**Tools you can try in the browser**

- **[Kaaval](https://shyamvasansathiskumar-ux.github.io/kaaval/)** ([code](https://github.com/shyamvasansathiskumar-ux/kaaval)): a permission layer between an AI coding agent and the shell, database and tools. Allow, ask or deny before anything runs. It replays six real incidents where agents destroyed data with nobody attacking them, and refuses all six. 39 tests; the site runs the real Python package through Pyodide.
- **[Kaappu](https://shyamvasansathiskumar-ux.github.io/kaappu/)** ([code](https://github.com/shyamvasansathiskumar-ux/kaappu)): a TOTP authenticator in plain Java, built from the RFCs, with an encrypted vault and Shamir secret-sharing backup so you can't lose your 2FA. 70 tests, including every RFC test vector.
- **[FairDoor](https://shyamvasansathiskumar-ux.github.io/fairdoor/)** ([code](https://github.com/shyamvasansathiskumar-ux/fairdoor)): rate limiting that can tell a deadline rush from a script flood. In simulation, per-IP limits made 68 of 300 students miss a deadline under attack; FairDoor, none.
